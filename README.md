# Magazine Website

A static digital magazine reader with a browser-based admin studio.

## Pages
- `index.html` — public magazine library and reader
- `admin.html` — upload page images and create editions in browser storage

## GitHub Pages
This repository includes a GitHub Actions workflow for Pages deployment.

**Important:** the browser-based admin is a prototype. Uploaded images are stored in the visitor's browser and are not a shared server database. For a production multi-user publishing system, connect the admin to cloud storage/database and authentication.
